div 태그 2
        요소 크기 계산해보기 
        전체 너비 = width + 좌우 padding + 좌우 border + 좌우 margin
        전체 높이 = height + 상하 padding + 상하 border + 상하 margin

        width: 200px
        padding: 20px
        border: 5px
        margin: 10px
        - 박스모델 크기를 계산하는 기준 
            box-sizing: content-box 기준 (기본값) 
            전체 너비 : 200 + 20 + 20 + 5 + 5  = 250px
            - 요소 자체의 너비: 200 + 40 + 10 = 250px
            - 레이아웃에서 차지하는 총 공간: 250 + 20(마진값추가) = 270px
